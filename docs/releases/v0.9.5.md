# qntm v0.9.5

qntm 0.9.5 delivers the full-stack security, correctness, and hygiene remediations from the November 12, 2026 audit across the Python SDK/CLI/MCP, TypeScript client (`@corpollc/qntm`), API Gateway Worker, Relay Worker, Charter Registry, browser/terminal UIs, and agent adapters.

```sh
uvx qntm --help
pip install --upgrade qntm
npm install @corpollc/qntm
```

## Highlights

- **Strict CBOR & Envelope Validation (`P0-1`, `P1-2`):** Enforce strict runtime byte-field type/length checks (`_require_bytes`), a 64 KiB pre-decode ceiling, and malformed-envelope skip handling across Python and TypeScript so crafted CBOR payloads cannot trigger pre-crypto memory exhaustion or stall receive cursors.
- **Gateway Origin Allowlists, Endpoint Binding & SSRF Protection (`P0-2`, `P1-6`):** Bind `gate.secret` vault credentials to explicit `allowed_origins` (derived from built-in services or configured origins), require exact `target_endpoint === pathname` agreement, normalize HTTP verbs to uppercase across threshold lookup and execution, encode recipe `{param}` substitutions safely, and block non-HTTPS, loopback, link-local, RFC 1918, and cloud metadata IPs.
- **Charter Registry Hardening (`P0-3`, `P1-5e`, `P2-4`, `P2-8`):** Remove unauthenticated HTTP `GET /backup` from the TCP metrics listener in favor of atomic `0600` local `snapshot.db` files inside the `0700` data directory, bind Grafana to `127.0.0.1` with anonymous access disabled, enforce 64-bit integer bounds in JCS canonicalization, apply per-IP Nginx rate limiting, and upgrade the Go toolchain floor to Go 1.27.4 (`GO-2026-6859`).
- **Group & Gateway Membership Authority (`P1-1`, `P1-3`):** Require group-administrator signatures on `gate.promote`, enforce vote-proof verification for delegated gateway controls using deterministic envelope timestamps, protect group creators against `gov.applied` removal and pre-genesis invite ordering, and serialize Python `conversations.json` mutations under an exclusive file lock.
- **Relay Hibernation, Rate Limiting & Monitoring (`P1-5`, `P2-7`):** Persist WebSocket authentication state across Durable Object hibernation, gate live broadcasts on completed `auth_ok`, normalize IPv6 rate-limit buckets to `/64` prefixes while exempting `GET /healthz`, bound D1 replay metadata, and paginate monitor cursor recovery.
- **Browser UI, Terminal UI, Adapters & CI (`P1-4`, `P1-7`, `P2`, `P3`):** Route browser UI receive processing through `receiveConversationEvent` and `verifyGatewayMessage`, strip terminal control sequences in TUI sidebars, harden OpenClaw/Channel/NanoClaw epoch and cursor state, pin GitHub Actions to 40-hex commit SHAs, and update Hono (`4.13.18`) and Playwright (`1.65.0`) dependencies.

See the [November 2026 Full-Stack Audit](../audits/2026-11-12-full-stack-audit.md) for full technical details and regression test coverage.
